# RepoBrain demonstration

## 0:00–0:35 — Open the pinned workspace

Open a prepared public snapshot by UUID. Point out the repository, immutable
commit, and readiness markers. Show that graph and index preparation are
explicit CLI tasks.

## 0:35–1:20 — Compare search and explore the graph

Search for a symbol. Compare lexical and graph-enhanced results on the same
snapshot. Explain that lexical scores and RRF scores use different scales.
Open an available provenance path, inspect a bounded neighborhood, and show
the equivalent directed relationships in the text view.

## 1:20–2:20 — Follow evidence to source

Use the disposable browser demonstration with its deterministic provider.
Open a citation and show exact source lines, snapshot commit, and the
GitHub permalink. Explain that structural citation checks bind an ID to
the supplied evidence. Claim correctness still requires semantic review.

Close by showing the evaluation implementation and preliminary dataset
status. Discuss retrieval comparisons once frozen benchmark runs exist.
